# Release 0.4.0 · focused skills and reference discovery

A user can now find a specific Nepal technology task, open its instructions and start with a matching working record. The release contains 100 original task skills plus the existing Dharma OS router, spanning banks, tech shops, schools, research, ICT procurement, engineering and business operations.

The offline source browser and Python helper search 16,884 canonical URLs: 117 Nepal institutional/media references and 16,767 conditional international technical references. Search supports source kind, topic, publisher and pagination. Individual task ZIP export refuses overwrites and rejects unknown or traversing skill identifiers.

International sources were collected from seven publisher indexes and remain explicitly unreviewed at page level. The metadata includes provenance hashes and count rules. Thirty-three bounded sample URLs responded during this release check; that convenience sample does not establish catalog-wide availability or content validity. No source bodies, credentials or client records are bundled.

Validation: 36 Python tests; three JavaScript core suites; syntax checks; all 101 skill entrypoints passed the skill validator. Direct local-file browser checks confirmed task search, source collection switching and pagination. An independent behavioral review of repair intake, bank regulatory crosswalk and causal-claim review exposed irrelevant automatic reference selection and missing intake fields; both were corrected and re-reviewed. This scoped review does not establish behavioral validation of all 100 tasks.

Existing assessment exports, selected payment observations and worked studies remain available. No empirical client outcomes, complete Nepal coverage, compliance certification or guaranteed business results are claimed. No API key is required for bundled offline use; live source review requires available research tools and case evidence.
